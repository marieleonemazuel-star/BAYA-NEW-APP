# Déployer gratuitement sur GitHub Pages
1. Crée un dépôt GitHub public, par exemple `baya-guide`.
2. Mets le contenu de ce dossier à la racine du dépôt.
3. Dans GitHub : Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Après quelques instants, GitHub fournit une adresse `https://TON-COMPTE.github.io/baya-guide/`.
5. Envoie ce lien aux personnes qui gardent Baya. Sur smartphone, elles peuvent choisir « Ajouter à l'écran d'accueil ».
