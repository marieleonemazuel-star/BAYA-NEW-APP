# Baya — Mon petit guide
PWA mobile-first, sans framework ni abonnement. Les photos fournies sont intégrées localement.

## Utilisation
Ouvrir `index.html` via un serveur local ou déployer le dossier sur GitHub Pages.

## Modifier le contenu
Le contenu des rubriques est dans `app.js`, les styles dans `styles.css`.

## Photos encore à ajouter
Si tu veux une rubrique dédiée au Kong rouge ou au bâton, ajoute les photos correspondantes dans `assets/` puis complète `data` dans `app.js`.
